# Major game genre families: 1980s–present

Genres overlap and change with markets, platforms, and communities. This is a broad taxonomy, not a claim to enumerate every subgenre. Dates below describe representative periods of visibility, not invention dates. Many foundations predate 1980: text adventures, tabletop RPGs, arcade action, strategy, and simulation.

| Family | Important branches | Representative milestones and development needs |
|---|---|---|
| Arcade action | maze chase, score attack, arena combat | Pac-Man (1980), Robotron: 2084 (1982); responsive input, enemy patterns, collision, score loops |
| Platform | single-screen, scrolling, cinematic, precision, 3D | Donkey Kong (1981), Super Mario Bros. (1985), Super Mario 64 (1996), Celeste (2018); jump feel, camera, collision |
| Shooter | fixed, scrolling, run-and-gun, FPS, third-person, tactical, hero, extraction, bullet hell | Gradius (1985), Doom (1993), Quake (1996), modern online shooters; projectiles, visibility, aiming, replication |
| Fighting / brawling | versus, beat-em-up, platform fighter | Double Dragon (1987), Street Fighter II (1991), Super Smash Bros. (1999); frame data, hitboxes, animation, rollback |
| Action adventure | exploration, stealth, survival horror, metroidvania, immersive sim | Metroid (1986), Metal Gear (1987), Resident Evil (1996), Deus Ex (2000); interconnected levels, inventory, perception |
| Role-playing | dungeon crawler, JRPG, CRPG, action RPG, tactical RPG, monster collecting | Wizardry (1981), Ultima (1981), Dragon Quest (1986), Diablo (1996); statistics, quests, progression, persistence |
| Roguelike / roguelite | turn-based dungeon, action runs, deckbuilding runs | Rogue (1980), Spelunky (2008), Slay the Spire (2019 full release); procedural generation, runs, item synergies |
| Adventure / narrative | parser, point-and-click, visual novel, interactive fiction, branching drama | Zork I (1980 commercial release), King's Quest (1984), The Secret of Monkey Island (1990); dialogue, puzzles, narrative state |
| Strategy | turn-based, real-time, 4X, grand strategy, tactics, auto battler | Civilization (1991), Dune II (1992), X-COM (1994); pathfinding, economy, AI, fog of war |
| Tower defense / MOBA | lane defense, hero lanes, hybrid strategy | Warcraft III custom-map ecosystem (2000s), League of Legends (2009); targeting, waves, team state |
| Simulation | flight, driving, life, city, business, farming, factory, space | Microsoft Flight Simulator (1982), SimCity (1989), The Sims (2000), Factorio (2020 full release); models, scheduling, agents |
| Racing | arcade, kart, circuit, rally, combat, sim racing | Out Run (1986), Super Mario Kart (1992), Gran Turismo (1997); vehicle dynamics, checkpoints, opponents |
| Sports | team, individual, extreme, management | longstanding arcade and computer traditions, Football Manager lineage; rules, animation, ball physics, tactics |
| Puzzle | falling blocks, match, logic, physics, spatial, programming | Tetris (1984), Lemmings (1991), Portal (2007); constraints, state transitions, solvability |
| Rhythm / music | timing lanes, dance, instrument, rhythm action | PaRappa the Rapper (1996), Dance Dance Revolution (1998); audio clocks, latency calibration |
| Survival / crafting / sandbox | block worlds, base building, open-ended creation | Minecraft (2011 full release), Terraria (2011); chunks, recipes, persistence, world simulation |
| Multiplayer worlds | MUD, MMORPG, social world, shared sandbox | text MUD foundations before 1980, Ultima Online (1997), World of Warcraft (2004); identity, persistence, sharding |
| Battle royale | last-player/team-standing, shrinking arena | mod-derived growth in the 2010s, PUBG (2017); matchmaking, large sessions, interest management |
| Party / social deduction | local minigames, asymmetric roles, cooperative communication | Mario Party (1998), Among Us (2018); session flow, hidden information, social systems |
| Cards / board / tabletop | collectible cards, digital board games, deckbuilders | computer chess predates this period; modern digital adaptations; rules engines, hidden state, deterministic replay |
| Educational / serious | learning, training, accessibility-centered practice | longstanding classroom and simulation use; assessment, feedback, domain accuracy |
| Idle / incremental | clicker, automation, prestige | prominent web/mobile growth in 2010s; large-number economy, offline progress |

## Cross-cutting labels

Open world, linear, cooperative, competitive, single-player, multiplayer, VR/AR, mobile, browser, procedural, and live service describe structure, interaction, platform, or operation rather than one exclusive genre. Horror is also a theme spanning several mechanical families. Casino and gambling software has distinct legal and financial requirements; no real-money implementation is included here.

## Learning route

Build a small maze game, then a platform prototype, then a tactical grid game. Reuse movement, clocks, collisions, state machines, maps, and inventory across genres. Add networking after the offline rules are explicit and testable. Consult the source registry for historical collections and original technical accounts.
