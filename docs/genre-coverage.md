# Genre-to-mechanics coverage

All 22 families in the genre history have a representative set of implemented core algorithms below. Every mechanic has links to its documentation, original Python source, and eight-language port contract. Each module has behavioral checks.

**Coverage means reusable educational code exists, not that an entire genre, engine, or multiplayer game is complete.** The remaining column records concrete work outside this implementation set. All 51 entries additionally have native Lua, C#, GDScript, TypeScript, JavaScript, C, Rust and Go kernels. Their numeric-array contracts and any scope differences from Python are documented per mechanic in PORTS.md and in [language conventions](language-ports.md).

Run `python3 tools/validate.py` from the repository root. See [validation evidence](validation.md). All included code is original and MIT licensed; no third-party game source was scraped.

## Maintaining the mapping

Edit [genre-coverage.json](../genre-coverage.json) and [catalog.json](../catalog.json), then run `python3 tools/build_indexes.py`. Run `python3 tools/build_indexes.py --check` to detect stale generated indexes. Do not add an implemented ID without real source and behavioral checks. Remaining systems are a backlog, not a list of completed implementations.
