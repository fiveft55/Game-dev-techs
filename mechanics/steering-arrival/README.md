# AI arrival steering

<!-- BEGIN PLAIN ENGLISH -->
## Plain-English explanation

Make an enemy or vehicle slow down as it reaches its target.

1. Draw an arrow from the object to the target.
2. Measure how far away the target is.
3. Far away means full speed. Nearby means a smaller speed.
4. Return the wanted speed in each direction; another controller must actually apply it.

See [PORTS.md](PORTS.md) for actual inputs, outputs and a worked example. The [beginner guide](../../docs/beginner-guide.md) explains common coding words.
<!-- END PLAIN ENGLISH -->

Status: implemented educational reference; Python 3 standard library.

Reduce desired speed inside a slowing radius. This computes desired velocity; apply acceleration limits separately to avoid instant changes in direction.

Read [`python/example.py`](python/example.py). Inline comments explain consequential choices. Run all examples' behavioral checks from the repository root with `python3 tools/validate.py`. Import this module into a game loop or editor; it has no automatic runtime side effects.
