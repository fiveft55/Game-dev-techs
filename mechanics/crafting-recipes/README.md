# Batch crafting recipes

<!-- BEGIN PLAIN ENGLISH -->
## Plain-English explanation

Turn ingredients into products, such as two pieces of wood becoming three planks.

1. Multiply ingredient and product counts by the number of batches.
2. Check that the backpack has every ingredient.
3. If anything is missing, change nothing.
4. Otherwise take the ingredients first, then add the products. Products cannot pay for their own ingredients.

See [PORTS.md](PORTS.md) for actual inputs, outputs and a worked example. The [beginner guide](../../docs/beginner-guide.md) explains common coding words.
<!-- END PLAIN ENGLISH -->

## Mechanic and algorithm

Consume a recipe for an integer number of batches and add its outputs only when all required ingredients are available. Compute inputs before outputs, so a recipe cannot use its own products to fund the same operation.

## Assumptions and limits

Independent implementation for a crafting inventory; no stations, unlocks, item instances, capacity limits, or database transaction. Counts are nonnegative integer quantities.

Tune the rules for your game and extend the tests before integrating. Educational coverage is not a full genre implementation or a production-readiness guarantee. The original Python API is preserved. Eight additional native kernels are available; see the portable contract for their API and scope differences.
